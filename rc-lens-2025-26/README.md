# RC Lens 2025-26: Team Performance & Style of Play

A deep dive into how RC Lens defended, attacked, and played across
the 2025-26 Ligue 1 season.

## Project structure

```
data/raw/         data as pulled (not tracked by git)
data/processed/   cleaned match/team-level CSVs
code/             one script per milestone (01-05)
figures/          saved charts and pass networks
```
